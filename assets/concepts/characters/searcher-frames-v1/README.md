# Ground searcher poses v1

The same child from SH04/SH05 is redrawn as 16 complete, full-body poses. The original 4×4 green-screen sheet is `searcher-16-pose-sheet.png`; `frames/` contains the transparent 448×448 RGBA frames used by the film.

Sequence: look up → shade the eyes → scan the canopy → inspect → take cautious steps → notice something → settle. SH04 uses the sequence at 3 fps; SH05 uses it at 2.5 fps and scales the same drawings down for the distant figure.

Regenerate the transparent frames with `npm run assets:searcher-frames-v1`.
